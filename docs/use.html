Use It

How to switch on the device, pick a mode, and control Blockly with one or two switches. Still need to build the device? Start with the build instructions.

Step 01

Getting Started

The switch interface plugs into a computer by USB and behaves like a keyboard. Each switch press sends a Blockly keyboard shortcut, so no extra software is needed on the computer.

  1. Plug one or two assistive switches into the 3.5 mm jacks. A2 is the select switch; A1 is the navigate switch.
  2. Connect the device to the computer with a USB-C data cable. The screen lights up with the mode-select screen.
  3. Open your Blockly environment and click once into the workspace so it has keyboard focus.
  4. Choose a mode (see Choosing a mode) and start pressing.
ℹ If the device was set up for macOS shortcuts and you are on Windows (or the other way round), some shortcuts won’t work. See Troubleshooting.
Step 02

Reading the Screen

Each mode has its own screen colour, so you can tell at a glance which mode you are in. A short text label shows the mode too, for anyone who finds the colours hard to tell apart.

ModeScreen colourLabel
Direct switch (Mode 0)TealSW1 / SW2
Single-switch (Mode 1)Purple, turning magenta while scanning1-SW
Two-switch (Mode 2)Blue2-SW

In single-switch and two-switch modes the screen is split into two panels.

What you seeWhat it means
Large symbol, right panel (mode colour)The shortcut that will be sent if you select now
Small symbol, left panel (grey)The shortcut that comes next
“1-SW” or “2-SW” at the top of the grey panelWhich mode you are in
Thick orange borderThis item opens a submenu
Orange “SUB” label at the bottom of the grey panelYou are inside a submenu
Dark bar along the bottom (single-switch only)A reminder of what the switch does right now, such as “Hold switch to scan”

Messages after a selection

After each selection the screen can flash a short message. Both messages can be turned on or off in the Shortcut Configurator (Step 2, On-screen Messages).

MessageWhat it means
Green “SENT!”The shortcut was sent to the computer. Turning this off makes the device faster, because the screen moves straight on.
Red “ERROR / Not sent”The shortcut did not reach the computer, for example because the USB cable is loose. Shows for 1 second. Recommended to keep on.
Green “OPEN”A submenu folder opened (it has no shortcut of its own to send).
Step 03

Choosing a Mode

When the device starts it shows the mode-select screen. Its three columns use the same colours as the modes themselves: teal for direct switch, purple for single-switch and blue for two-switch. Choose a mode with an onboard button or an external switch.

ModeOnboard buttonExternal switch
Mode 1 — Single-switch scanningD1Click A2 (select)
Mode 2 — Two-switch navigationD2Click A1 (navigate)
Mode 0 — Direct switchD0Double-click A1 or A2

To get back to the mode-select screen from any mode, press D0 or the board’s RESET button. In Mode 0 you can also hold a switch for 1.5 seconds.

ℹ A single click on an external switch waits a moment (0.4 s) to check whether a second click is coming. That short pause is expected. The onboard D1 and D2 buttons switch mode instantly.
Mode 1

Single-Switch Scanning

One switch (A2) does everything. The device steps through the shortcut list for you, and you press when the one you want appears. A bar along the bottom of the screen always says what the switch will do next.

Short pressSend the current shortcut
Hold (2 s)Start auto-scanning, then let go
Press during scanSend the current shortcut and stop scanning
D0Return to mode select

What the hint bar shows

  1. “Hold switch to scan” — the device is waiting. The screen is purple. A short press sends the shortcut shown.
  2. “Keep holding...” — once you hold past a short press, the bar fills up. Keep holding until it is full.
  3. “Press to select” — scanning has started and the screen turns magenta. Let go of the switch, then press again when the shortcut you want appears.
✓ Scanning speed and hold time can be changed in the Shortcut Configurator.
Mode 2

Two-Switch Navigation

One switch moves through the list and the other sends. You set the pace, so this is usually faster than scanning. The screen is blue, with “2-SW” at the top of the grey panel.

A1 pressMove to the next shortcut
A2 pressSend the current shortcut
D0Return to mode select
Mode 0

Direct Switch

Each switch sends one action straight away, with no list to move through. This suits users who need a simple, low-effort input, or who want switches for mouse clicks, scrolling or media keys.

A1 tapSwitch 1 action (default: Enter)
A2 tapSwitch 2 action (default: Tab)
Hold A1 or A2 (1.5 s)Return to mode select
D0 or RESETReturn to mode select

The screen shows SW1 on the left and SW2 on the right in two shades of teal, each with the symbol for its action. If “SENT!” messages are on, the side you press flashes green when the action is sent. If an action fails, a red “ERROR” screen appears (when error messages are on).

Actions a switch can send

TypeWhat it doesExample
Keyboard keyPress any key or key combinationEnter, Tab, Ctrl+C, Cmd+Space
Mouse clickLeft, right or middle clickLeft click to activate
Mouse scrollScroll up or down per pressScroll down a page
Mouse moveMove the pointer per pressNudge the cursor right
Media controlPlay/pause, volume, track skip, mute, brightnessPlay/pause music
ℹ Set both switch actions in the Shortcut Configurator under Mode 0 — Direct Switch Actions.
Step 04

Using Submenus

Long lists are slow to scan, so related shortcuts can be grouped into submenus. Submenus work in single-switch and two-switch modes.

  1. An item with a thick orange border opens a submenu. Select it like any other item.
  2. If the item has its own shortcut, that shortcut is sent first. For example, a Cmd+B item opens Blockly’s menu on the computer, and the submenu then lists the choices for that menu. A submenu without a shortcut is just a folder and shows “OPEN”.
  3. The list changes to just the items in that submenu, and an orange SUB label appears at the bottom of the grey panel.
  4. Some submenus return to the main list automatically after you pick one item.
  5. Others let you pick several items in a row. Choose the back item (shown as <) at the end of the list when you are done.
Step 05

Customising Shortcuts (optional)

The device works out of the box with built-in shortcuts. To change the shortcut list, scan order, timing, on-screen messages or Mode 0 actions:

  1. Open the Shortcut Configurator in your browser.
  2. Choose macOS or Windows, then adjust shortcuts and timing. To edit an existing setup, load its config.py first.
  3. Under On-screen Messages in Step 2, choose whether to show “SENT!” after each selection and “ERROR” if a send fails. Experienced users often turn “SENT!” off for speed.
  4. Click Generate config.py, then Download config.py.
  5. Copy the file to the root of the CIRCUITPY drive. The device restarts with the new settings.
Step 06

Web Display (optional)

The onboard screen is small. The Web Display shows the same information large and high-contrast on the computer screen, with optional text-to-speech that reads out each shortcut.

  1. Open the Web Display in Chrome or Edge.
  2. Click Connect and choose the device from the list.
  3. Turn on text-to-speech or sound if wanted, then use the switches as normal.
⚠ The Web Display needs Chrome or Edge on a computer (it uses Web Serial). Text-to-speech is computer-only, and the tool has not yet been tested on mobile devices.
Step 07

Troubleshooting

The shortcut seems to send but nothing happens in Blockly
Click into the Blockly workspace so it has keyboard focus. If only shortcuts with Ctrl or Cmd fail, the configuration is probably for the other operating system: regenerate config.py with the right OS selected.
Single-switch mode sends instead of scanning
Keep the switch held until the bar along the bottom fills and the screen turns magenta. A short press sends the current shortcut. If you let go before the bar fills, nothing is sent and scanning doesn’t start.
The screen shows “ERROR / Not sent”
The shortcut didn’t reach the computer. Check the USB cable is firmly connected and carries data, and that the computer is awake. In direct switch mode, also check that the action type (for example mouse or media) is supported.
The device pauses after every selection
That pause is the “SENT!” message. Turn it off in the Shortcut Configurator under On-screen Messages, then copy the new config.py to the device.
I’m stuck in a mode
Press D0 or RESET to return to mode select. In Mode 0, hold either switch for 1.5 seconds.
I’m stuck in a submenu
Move to the back item (<) at the end of the submenu and select it.
The Web Display can’t find the device
Use Chrome or Edge, check the USB cable carries data (not just power), and close any other page or program connected to the device.
