Step 03

Check It Works

  1. Connect the board to a computer with a USB-C data cable. A drive called CIRCUITPY appears.
  2. Make sure code.py is in the root of CIRCUITPY, along with the lib folder.
  3. The screen shows the mode-select screen with three zones: D0, D1 / A2 and D2 / A1.
  4. Plug a switch into each jack and click it. The device should enter a mode and show a shortcut symbol.
✓ Your switch interface is built. Head to the Use It guide to choose a mode, learn the controls and customise shortcuts.
